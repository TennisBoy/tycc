# Memory

Contextual and time-bound state derived from interactions and events.

Store current focus, active decisions, known blockers, and session context here. Content here expires — update it when it becomes stale.

For durable, generalizable patterns and gotchas that do not expire, use `team-lead/knowledge/`.

## Files

- `current-focus.md` — what the project is currently working on
- `recent-decisions.md` — decisions made in recent sessions (expire after ~2 sprints)
- `active-blockers.md` — known blockers and work in progress
- `session-context.md` — last session state, auto-updated by `complete-the-work`
